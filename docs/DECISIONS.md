## Prosedur perubahan
1. **Penyesuaian Parameter Aturan Eksisting:** Admin PT SIS dapat mengajukan perubahan nilai parameter (misal: penyesuaian toleransi selisih dari 0 menjadi 1000 IDR) melalui API `PATCH /admin/rules/{id}/params` dengan menyertakan alasan tertulis dan referensi persetujuan. Sistem akan membuat record versi baru di `validation_rules` dan mencatatnya ke dalam `audit_log`.
2. **Penambahan Aturan / Logika / Fitur Baru:** Penambahan logika validasi baru, penanganan tipe dokumen baru, atau modifikasi alur kerja berada di luar cakupan maintenance reguler dan WAJIB diproses melalui **Change Request (CR)** resmi sesuai alur di [OPERATIONS](OPERATIONS.md). DILARANG mengubah logika bisnis secara diam-diam melalui prompt atau script ad-hoc.
